# Credit Card Fraud Detection — dbt Analytics Project

A data engineering project using dbt to build fraud detection infrastructure on BigQuery.

## Project Structure

- `models/staging/` — Clean transaction and customer data
- `models/marts/` — Fraud indicators and risk scores
- `tests/` — Data quality checks
- `data/` — Raw Kaggle dataset (gitignored)
